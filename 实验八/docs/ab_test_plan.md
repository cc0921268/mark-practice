# A/B 测试方案与指标

研究问题：蓝牙耳机新品推广页面，展示实测条件和佩戴步骤的方案 B，是否比普通参数摘要方案 A 更能提高点击意愿与购买意愿？

目标为 20–30 名自愿参与者；按匿名编号奇偶交替分配 A/B，争取各 10–15 人。每人仅看一个方案，然后填写 1–5 分点击意愿、1–5 分购买意愿及开放反馈。不得收集姓名、电话、邮箱等信息。相同设备或近似环境下展示，同一人只提交一次。实施前固定两版素材与问卷。真实实施时记录日期、招募渠道、完成数与排除原因。

核心指标：高点击意愿率 = 点击意愿 ≥4 的人数 / 该方案有效答卷数；高购买意愿率 = 购买意愿 ≥4 的人数 / 该方案有效答卷数。辅助指标为两项平均分。分子、分母和样本量须同时报告。反馈按原文人工归类，不能从少量回答推断总体购买行为。此设计观察自报意愿，没有实际点击、成交或随机抽样；样本小，不能作显著性或因果结论。

`data/sample/ab_simulated.csv` 为 **模拟演练**，不是参与者回答。真实测试完成后应单独导入真实匿名 CSV，并另写真实测试报告；现有输出不得改名为真实结果。
