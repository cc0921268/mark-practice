# 蓝牙耳机新品推广 Campaign 策略草案

**版本 v0.7；审核状态：待人工审核，尚未发布。**结构化结果见 `outputs/campaign_strategy.json`，完整步骤文件见最新正式运行目录的 `09_campaign.json`。

## 为什么做

实验四真实评论定向样本中，“设备失效”为 9/30，“电池与充电”为 8/30；计数和分母由 pandas 在本次运行的 `consumer_outputs/pain_ranking.csv` 计算。实验六内容机会矩阵中，设备可靠性 9/30 评论提及、竞品耳机标题 0/13 命中相应词，机会分数 30.00。该 0/13 只表示**本次竞品标题**未命中，不证明竞品全渠道没有相关内容。

## 为谁做

目标假设是曾遇到单耳停用或充电困扰、希望先了解适用条件的耳机使用者。证据来自原评论 ID `RZ80S0WTLE5XV`、`R14S44XNYWAJ6S`、`R3I5STGPGGKF8T`；各引句可在本次 `content_outputs/evidence_record.csv` 追溯。30 条评论为定向样本，不能将该描述当作总体消费者画像。

## 凭什么做

本次 Workflow 实际调用实验四统计组件、实验五竞争计算组件、实验六机会组件和 Brand Voice 检查。竞品对比以 Skullcandy 为分析焦点，但清波 ClearWave 是**课程虚构品牌**，不是 Skullcandy 的官方新品。竞品标题审查示例 ID `147081484523`、`156108842069`、`157389264418` 均在商品清洗文件中；完整 13 条审查 ID 在内容机会证据表中。需要先完成真实产品测试，才能把任何性能结论写成对外承诺。

## 传播主题与渠道

传播主题：“先讲清测试条件，再讨论耳机可靠性”。Brand Voice 要求使用条件化、可核对的说法，不写“永久”“零故障”或未证实的领先声明。

| 渠道 | 角色 | 预期指标 |
|---|---|---|
| 产品详情页 | 展示测试条件与保修边界 | 说明模块点击人数 / 详情页访问人数 |
| 短视频 | 演示可复核的单耳与充电排查步骤 | 完整观看人数 / 视频曝光人数 |
| 售后知识页 | 帮助使用者定位排查路径 | 完成排查人数 / 知识页访问人数 |

所有指标基线待收集；本草案没有预算、投放排期或真实产品实测结果。人工审核点需核查产品事实、评论引用许可、渠道资源和预算后再决定是否对外使用。流程没有自动发布功能。
