# 竞争指标字典与公式 v0.5

**焦点品牌：Skullcandy。**所有品牌名来自两份输入的 `brand` 字段。评论中的品牌和商品列表中的品牌仅做品牌级对照，没有共同消费者 ID 或共同商品 ID；“消费者重合度”是**关注痛点重合的代理**，不能解释为真实消费者交集。完整输入与口径见 `docs/source_record.md`。

## 指标、单位、来源、缺失处理

| 指标 | 计算与单位 | 数据来源 | 缺失处理 |
|---|---|---|---|
| 消费者关注痛点重合度 `C` | 对每个痛点标签求品牌内提及率 `p(tag)=带该标签的评论数/该品牌评论样本数`；`100×Σmin(p焦点,p竞品)/Σmax(p焦点,p竞品)`，范围 0–100 分 | 实验四 `encoded_reviews.json` 的 `pain_tags`、`review_id` | 任一品牌评论数少于 3，或两边均无痛点标签，则 `C` 不可靠，整项威胁指数不排名。缺失不填 0。 |
| 产品结构重合度 `P` | 从商品标题编码“耳塞/头戴/未明确”与“标题提及 ANC/未提及 ANC”的组合；`100×Σmin(焦点产品段占比,竞品产品段占比)`，范围 0–100 分 | 实验三 `clean_data.csv` 的 `title`、`listing_id` | 标题不明确时归入 `unspecified`，不猜测产品类别；品牌没有商品列表则不进入候选。商品数少于 3 显示警示。标题未提及 ANC 不表示商品没有该功能。 |
| 价格重合度 `R` | 按 USD 标价划为 `<50`、`50–99.99`、`100–199.99`、`≥200`；`100×Σmin(焦点价格带占比,竞品价格带占比)`，范围 0–100 分 | 实验三 `clean_data.csv` 的 `price_usd` | 清洗数据已拒绝无效价格；若上传资料缺字段或无效值则明确报错，不计算。 |
| 品牌热度 `H` | 每品牌取商品列表 `reviews_count` 中位数，对所有同时出现在商品与评论数据的候选品牌作百分位排名 `rank(pct)×100`，范围 0–100 分 | 实验三 `clean_data.csv` 的 `reviews_count` | 清洗数据中该字段完整；商品数少于 3 显示警示。它是**商品评论数量的相对代理**，不是搜索热度、销售额或真实市场份额。 |

产品与价格分布的交集采用直方图交集，两个分布完全相同得 100 分，无共同类别得 0 分。`C` 使用逐标签提及率的加权 Jaccard；一条评论可带多个标签。所有分数的分母均来自本项目的非随机样本，不能推断市场总体。

## 威胁指数与权重

`竞争威胁指数 T = 0.30×C + 0.25×P + 0.20×R + 0.25×H`。

| 指标 | 权重 | 作用 |
|---|---:|---|
| 消费者关注痛点重合度 | 30% | 衡量评论关注问题的相似性 |
| 产品结构重合度 | 25% | 衡量商品形态及标题卖点的接近程度 |
| 价格重合度 | 20% | 衡量定价带的相互覆盖 |
| 品牌热度 | 25% | 衡量候选品牌商品评论数量的相对位置 |
| **合计** | **100%** | 指数范围 0–100 |

权重是本实验的分析假设，不是经因果识别得到的最优值。候选品牌必须在两份数据中都出现；评论样本低于 3 条时 `rank_status=insufficient_review_sample` 且 `threat_index` 为空。单个商品列表的 Jabra 仍可试算，但 `product_sample_warning=true`，结论应谨慎。`outputs/scores.csv` 给出四个分数和总分，`outputs/evidence.csv` 给出每一指标的来源字段和示例原始 ID。排名按总分降序，分数相同时按品牌名稳定排序。

## 手工复算示例

Sennheiser 相对 Skullcandy 的四项分数约为 `23.5294、79.3269、71.1538、83.3333`。按基准权重：`23.5294×0.30 + 79.3269×0.25 + 71.1538×0.20 + 83.3333×0.25 ≈ 61.9547`。程序使用未四舍五入的中间值计算总分，最后保留四位小数；用表格中已四舍五入的分数手算可能产生末位差异。
