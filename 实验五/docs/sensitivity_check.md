# 权重敏感性检查

基准公式权重为 `C/P/R/H = 30/25/20/25`，合计 100%。脚本在 `outputs/sensitivity.csv` 记录每个情景的完整权重、指数、排名与样本状态。所有情景都重新计算指数，**不改变四个原始指标**。

| 情景 | C/P/R/H | Sennheiser | Jabra | 排名变化 |
|---|---|---:|---:|---|
| 基准 | 30/25/20/25 | 61.9547（1） | 25.2570（2） | 基准 |
| 消费者 +10 个百分点 | 40/20/15/25 | 56.7836（1） | 29.7872（2） | 不变，差距缩小 |
| 产品 +15 个百分点 | 20/40/15/25 | 67.9431（1） | 22.6019（2） | 不变，Sennheiser 优势扩大 |
| 价格 +15 个百分点 | 20/20/35/25 | 66.3084（1） | 18.8519（2） | 不变，Jabra 的价格重合为 0 |
| 热度 +20 个百分点 | 20/20/15/45 | 68.7443（1） | 22.1853（2） | 不变，Sennheiser 热度分较高 |
| 消费者主导压力测试 | 70/10/5/15 | 40.4610（2） | 42.6484（1） | **互换**；Jabra 的消费者代理得分较高 |

压力测试只说明排名依赖权重。Jabra 仅有 1 条商品列表，70% 消费者权重也放大了定向评论样本的偏差，因此不能把互换后的第 1 名当作稳健市场结论。Apple、JBL、Sony 的评论数分别为 1、2、1，所有情景均保持“不可排名”，缺失不被填成 0 分。每情景权重之和由测试自动检查为 100%。
