# 实验 1 需求 Prompt（个人作业）

> 请在 `实验一` 项目内实现一个不调用大模型 API 的本地营销 CSV 分析工具。输入为教师提供的 `marketing_data.csv`，字段为 `brand,product,price,rating,sales`；必须校验 `brand,price,rating`，提示所有缺失字段；按品牌计算有效记录的平均价格和评分，显示柱状图，支持品牌筛选。空值和无效数值所在行跳过并给出行号。原始上传文件只追加保存，不允许覆盖；清洗后的分析结果与处理日志分别保存。准备正常、缺字段、空值三套样例，并记录来源、采集日期、字段用途。提供无需大模型 API 的启动说明、测试记录、Debug 日志和截图。全部文件必须位于项目文件夹，不使用 Git 版本管理。

## 个人职责映射

个人独立承担需求、数据、流程、产品和测试工作，按验收标准逐项自测，并保留可供教师复核的测试记录。
