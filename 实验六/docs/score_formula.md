# 需求—竞品标题覆盖矩阵与机会公式

## 从数据到主题

需求主题由实验四评论痛点标签映射：设备可靠性、续航与充电、连接稳定性、佩戴适配、价格与价值、声音表现、降噪体验、包装状态、商品状态、售后支持、配送和口味。它们是**痛点导出的内容主题**，并不等于经代表性调查验证的总体需求。每个主题的评论证据和竞品标题审查 ID 存于 `outputs/evidence_record.csv`。

竞品标题覆盖使用实验五可排名品牌 Sennheiser 与 Jabra 的 13 条耳机商品标题。正则词组见 `src/content_opportunity.py` 的 `THEMES`；仅统计标题明确出现的词。实验五 `selling_points.csv` 用于核对 ANC 标题提及数。排除 USB Dongle 的规则及 ID 见 `docs/source_record.md`。

## 计算

| 字段 | 公式、单位与分母 |
|---|---|
| 用户主题提及数 | 含某痛点标签的不同评论数；同一条评论每主题最多计 1 次 |
| 用户重要度代理 `I` | `100 × 主题提及评论数 / 30 条评论`，单位为百分比；定向样本内的关注度，不代表总体需求 |
| 竞品标题覆盖率 `C` | `100 × 标题命中数 / 13 条已审查标题`，单位为百分比；不代表完整营销内容覆盖 |
| 内容机会分数 `O` | `I × (1 - C/100)`，范围 0–100，单位为分 |

为避免伪机会，只有**至少 3/30 条评论提及**且**竞品标题覆盖率不高于 25%**、分数大于 0 的主题标为 `opportunity` 并进入 Brief。少于 3 条评论且覆盖率低于 25% 的主题标为 `pseudo_gap_low_user_interest`，不因竞品标题未覆盖就强行推荐。覆盖较高或分数为 0 的主题标为 `covered_or_low_gap`。阈值为本实验的筛选假设，需随样本扩大而重估。

**手工复算：**设备可靠性 9/30 条评论提及、0/13 标题命中，`O=30.00×(1-0/13)=30.00`。续航与充电 8/30 条评论提及、1/13 标题命中，`O≈26.67×(1-1/13)=24.62`；程序用未舍入的 8/30 计算后再保留两位。口味 0/30、0/13，机会分数 0，明确排除。连接稳定性虽有 6/30 条评论，但 13/13 标题都提及无线或蓝牙，分数 0；“标题提及”不等于解决了连接问题。

## 证据解释

`outputs/evidence_record.csv` 对每个主题包含三类记录：原评论 ID 与精确引句、命中的竞品商品 ID 与标题词段、审查过的全部竞品商品 ID 及正则命中数。覆盖为零的主题仍有完整审查 ID 列表；这是“在 13 条标题中未命中”的可复核证据，而不是竞品全渠道缺席的证明。
