# 第 5 周获取方式比较

| 方式 | 优点 | 本实验限制 | 结论 |
|---|---|---|---|
| 静态 HTML 抽取 | 可直接保留页面字段与页面地址 | 实时商品页面可能动态加载，且需要单独核查站点访问条款；不适合在本实验中建立稳定快照 | 未采用 |
| 公开 API 导入固定数据集 | 可固定版本和校验哈希，字段结构清晰；公开 GitHub API 可复现同一文件 | 必须注明原始数据集许可和样本筛选偏差 | 采用；固定 blob 校验后导入 |
| 教师数据集导入 | 课程口径可能更贴合作业要求 | 本次没有收到教师数据文件，不能假设其字段或许可 | 未采用 |

先从竞争问题反推 `title,brand,price,rating`，再增加 `reviews_count,watchers_count,scrape_timestamp` 用于互动和时间核对。第 5 周先保存 `data/sample/first_50.csv`；它严格等于 `data/raw/raw_data.csv` 的前 50 条。第 6 周扩至 480 条，清洗后 411 条。
