# 清洗规则与质量解释

执行命令：`python src/clean.py`。脚本核对 `raw_data.csv` 与采集日志中的 SHA-256 后才处理，清洗结果可重复覆盖，原始文件不覆盖。机器可读的逐类数量见 `outputs/cleaning_log.json`，统计见 `outputs/quality_statistics.json`。

| 类别 | 规则 | 本次数量 |
|---|---|---:|
| 重复值删除 | 按 `listing_id` 去重；保留抓取时间较晚的记录，同时间优先保留有关注数的记录，再同则保留先出现的行 | 69 |
| 必需值为空或行结构异常删除 | 编号、名称、品牌、证据类型、评论数等无法使用时删除 | 0 |
| 日期无效删除 | 不能按 ISO 日期时间解析的记录删除；有效日期保留日期部分，不编造时区 | 0 |
| 价格无效删除 | 非数值、非有限或小于等于 0 的价格删除 | 0 |
| 评分无效删除 | 非数值或超出 0–5 的评分删除 | 0 |
| 货币不同删除 | 非 USD 不做未经证实的汇率转换 | 0 |
| 品牌别名修改 | 大小写标准化；`Beats by Dr. Dre` 归为 `Beats`，其余映射见代码 | 52 |
| 关注数无效修改 | 非空但非法的值置空，不猜测为 0；原本为空也保持空白 | 0 |
| 价格异常保留 | 阈值为 `Q3 + 3 × IQR = 384.08 USD`；超过阈值标 `price_outlier=true`，保留供人工审查 | 5 |

**统计结果：**480 条原始抽取记录，去重后 411 条；八个分析字段的非空比例为 **95.47%**，高于 90%。其中七个字段为 100%，`watchers_count` 为 63.75%；总体比例是按八列全部单元格计算，不以选择性剔除关注数列来抬高数字。74 个品牌；清洗后价格范围 4.00–526.99 USD。清洗后标题含蓝牙词的 164 条，其余 247 条为来源无线标记代理。

**手工抽查：**原始编号 `157620004131` 的 Shokz 商品为 149.99 USD、评分 5.0、评论数原文 `1.0`、抓取日期 2026-01-17；清洗后分别为 `149.99`、`5.0`、`1`、`2026-01-17`。编号 `389238481744` 的 Apple 商品价格 `169.99`、关注数 `109.0`，清洗后为 `169.99`、`109`。这两条在 `tests/test_pipeline.py` 中固定核对。
