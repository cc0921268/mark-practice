# 数据伦理检查表

| 检查项 | 结果与处理 |
|---|---|
| 公开可访问 | 来源是可公开读取的 GitHub 数据集快照，项目记录固定版本和链接。 |
| 许可 | 数据集声明 CC BY-NC 4.0，仅用于本次非商业课程学习；保留来源与许可署名。 |
| 个人敏感信息 | 导入脚本仅选择商品、价格、评分、时间和汇总互动字段；不导入卖家用户名、位置、个人评论或联系方式。抽样标题未发现可识别的邮箱或电话号码。 |
| 最小化采集 | 不重新抓取站点账户和网页；只从公开快照抽取 480 条。 |
| 原始保护 | `raw_data.csv` 用独占新建模式写入，采集脚本拒绝覆盖；清洗前后都校验原始文件 SHA-256。 |
| 分层存储 | 原始 CSV 在 `data/raw/`，清洗 CSV 在 `data/processed/`，采集与清洗日志在 `outputs/`。 |
| 推断边界 | 无评论正文，不能做评论内容分析；无线代理样本不能断言具体蓝牙协议；评分完整率受筛选条件影响。 |
| 外部服务 | 不调用大模型 API；本地页面绑定 `127.0.0.1`。 |
